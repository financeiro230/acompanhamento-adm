# Acompanhamento ADM — Agenda / Kanban

Sistema da equipe: agenda (eventos e missões, com repetição) + kanban de demandas, com espaço individual para cada pessoa.

- Site: publicado pelo GitHub Pages
- Banco e login: Supabase (cada pessoa só vê o próprio espaço; o administrador vê todos — regras no banco, arquivo `supabase-setup.sql`)
- A chave usada no código é a chave pública (publishable) do Supabase, feita para ficar no site.
